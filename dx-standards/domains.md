# Suite Domains

Canonical domain mapping for the suite. The README mirrors this table; skill directories are NOT moved (plugin paths and self-contained installs stay stable). Domain counts must sum to the plugin.json skills-array count — `validate_skills.py` enforces agreement.

## Domain model

1. **Learn & Adopt** — discover, understand, evaluate, onboard to first verified value.
2. **Build** — day-to-day authoring: tools, surfaces, feedback loops.
3. **Validate** — prove it works before it ships.
4. **Ship & Operate** — release, run, and support in production.
5. **Participate & Extend** — community, contribution, extension ecosystems.
6. **Measure & Improve** — instrument, measure, iterate.
