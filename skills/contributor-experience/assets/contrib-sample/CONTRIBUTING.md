# Contributing

Thanks for your interest. First-time contributors are welcome; look for issues labeled `good first issue`.

## Setup

Run `make setup` once, then `make test` to verify your environment.

## Making a change

1. Create a branch from `main`.
2. Make your change and add tests.
3. Run `make test` locally until green.
4. Open a pull request; CI runs the same checks.

## Review

Maintainers review pull requests. First responses usually land within a few days.

## Sign-off

All commits must be signed off (DCO).
