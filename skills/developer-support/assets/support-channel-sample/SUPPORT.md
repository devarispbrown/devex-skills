# Support

How to get help with Widget. Read this before opening anything.

## Get help

- **Documentation:** the docs/ guides and API reference answer most how-to questions. Search first.
- **Community:** ask in the Widget forum. Search the archive before posting; answered threads are kept.
- **Status:** check status.widget.example for outages and incidents before reporting a service problem.

## Report a bug

Open a bug report through the issue tracker and include the diagnostic fields below. The error output already contains the request ID and trace ID; copy them from there.

## Billing

For invoices, plan changes, and quota questions, email billing@widget.example with your account email.

## Data loss

If you believe data is missing, deleted, or corrupted, do not retry destructive operations. Open an emergency ticket immediately.

## Diagnostics we need

Product version, SDK version, request ID, trace ID, environment, configuration with secrets removed, and sanitized logs. A report missing request ID or trace ID is returned for completion.

## What happens next

- Acknowledgment within 1 business day.
- Bug reports confirmed as defects escalate to engineering; you are updated on the ticket.
- Emergencies are handled outside the queue.
