# MySQL Connector

Connects the platform to a MySQL database.

## Configuration

| Variable | Default | Description |
| --- | --- | --- |
| `MYSQL_HOST` | `localhost` | Database host |
| `MYSQL_PORT` | `3306` | Database port |
| `MYSQL_SSL_MODE` | `require` | TLS mode |
