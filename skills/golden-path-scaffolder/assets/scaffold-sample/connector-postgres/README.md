# Postgres Connector

Connects the platform to a Postgres database.

## Configuration

| Variable | Default | Description |
| --- | --- | --- |
| `POSTGRES_HOST` | `localhost` | Database host |
| `POSTGRES_PORT` | `5432` | Database port |
| `POSTGRES_SSL_MODE` | `require` | TLS mode |
