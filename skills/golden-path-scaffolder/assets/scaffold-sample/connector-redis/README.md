# Redis Connector

Connects the platform to a Redis database.

## Configuration

| Variable | Default | Description |
| --- | --- | --- |
| `REDIS_HOST` | `localhost` | Database host |
| `REDIS_PORT` | `6379` | Database port |
| `REDIS_DB` | `0` | Logical database index |
